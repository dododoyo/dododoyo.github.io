# Protfolio Website

This is the repository contains code for my portfolio website. It includes a header section with a navigation bar, a hero section with a background image and a call-to-action button, a skills section with a progress bar for each skill, a timeline section with a list of events, a blog section with a list of articles, and a footer section with social media links and copyright information.

## Contents

The code in this repository specifically includes the timeline and blog sections. The timeline section includes a list of events with their respective year, description, and number. The blog section includes a list of articles with their respective title, description, author image, and read more button.

The code also includes a script tag that links to an external JavaScript file named "app.js".

## Usage

To use this code, simply clone the repository and open the `index.html` file in your web browser. You can customize the content and styling to fit your needs.
